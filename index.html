AI Field Assistant

Enter specimen details in the New Specimen tab, then use “Analyze with AI”. The assistant suggests:

  • Possible identification based on tests and description
  • Rough value range for educational / craft use (BC field material)
  • Disposition recommendation: Throw it back · Educational specimen · Jewelry / lapidary · Crush / process

Currently a local rules-based assistant. Can be extended to call an external AI endpoint (Grok, etc.) for richer analysis while keeping data private.

Questions to refine the AI:

  • What hardness range or specific mineral families are most common in your Oliver / South Okanagan work?
  • How should value estimates factor in ethical small-scale mining and one-of-a-kind craft premium?
  • When would you prefer “educational” over “jewelry” for a solid but less colorful piece?
